# CareerTrack — Career & Placement Tracker

A modern, responsive dashboard that helps students organize job applications, track placement progress, monitor application statuses, and manage their career goals in one place.

## ✨ Overview

**CareerTrack** is a frontend-based career management application designed to simplify the job application process. It provides a clean dashboard where users can manage job opportunities, review application statistics, and keep track of their placement journey.

## 🚀 Features

- **Modern Dashboard:** Clean interface with a sidebar and welcome banner.
- **Application Management:** Add, edit, and delete job application records.
- **Application Status Tracking:** Organize applications by their current status.
- **Analytics Dashboard:** View application statistics and progress summaries.
- **Weekly Goal Tracker:** Set and monitor weekly application goals.
- **Theme Toggle:** Switch between available visual themes.
- **Local Data Persistence:** Save application data in the browser using LocalStorage.
- **Responsive Design:** Adapted for desktop, tablet, and mobile screens.
- **Interactive UI:** Smooth animations, status badges, and user-friendly empty states.

## 🛠️ Tech Stack

- **HTML5** — Application structure
- **CSS3** — Styling, layouts, animations, and responsive design
- **JavaScript** — Interactive functionality and application logic
- **LocalStorage API** — Browser-based data persistence
- **Git & GitHub** — Version control and source code hosting

## 💻 Getting Started

### Prerequisites

You need a modern web browser and a code editor such as Visual Studio Code.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Abhishek-2527/CareerTrack.git
   ```

2. Open the project folder:

   ```bash
   cd CareerTrack
   ```

3. Open `index.html` in your browser, or use the **Live Server** extension in VS Code.

No backend server or database installation is required for the current version.

## 💾 Data Storage

CareerTrack uses the browser's LocalStorage to preserve application records and selected preferences between page reloads.

**Note:** Data is stored locally in the browser. It is not automatically synchronized between different devices or browsers. Clearing browser site data may remove saved application records.
